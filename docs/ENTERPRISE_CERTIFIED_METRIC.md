# 企业级认证指标发布门禁

上海如静知华信息科技有限公司（[知华科技](https://www.zhuatech.cn/)）为 BI 开源版增加指标认证能力。

`POST /api/enterprise/bi/certified-metric-release` 在指标发布前检查口径审批、数据血缘、行级权限、刷新 SLA、质量问题与对账差异，输出 `RELEASE / REVIEW / BLOCKED` 及可执行整改动作。该接口适合接入指标平台的发布流水线；生产使用时应把审批、审计与告警持久化到企业基础设施。

关键控制包括责任人必填、严重质量问题硬阻断、刷新超时硬阻断、差异容忍度复核以及认证版本留痕。
